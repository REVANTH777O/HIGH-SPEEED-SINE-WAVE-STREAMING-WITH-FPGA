## Clock domains

1. SYS clock: 50 MHz PL clock from EDGE ZYNQ-7020 U18.
2. FIFO read clock: generated internally for the current prototype.
3. SPI clock: generated by spi_master.
4. SPI slave is clocked directly by SPI SCLK.

## File ownership

rtl/
- asynch_fifo.v             : asynchronous FIFO
- dds_capture.v             : registers DDS output before FIFO write
- dds_top.v                 : wrapper around Vivado DDS Compiler IP
- clock_divider.v           : prototype clock divider
- spi_controller.v          : FIFO-to-SPI sequencing
- spi_master.v              : 16-bit SPI transmitter
- spi_slave.v               : 16-bit SPI receiver
- uart_fifo_dds_core.v      : clean system integration

tb/
- asynch_fifo_tb.v          : FIRST test; FIFO only
- uart_fifo_dds_loopback_tb.v : SECOND test; complete digital loopback

constraints/
- edge_zynq_7020.xdc        : known board clock/LED/switch pins

## Simulation order

TEST 1:
tb_asynch_fifo
  -> prove FIFO independently.

TEST 2:
DDS simulation
  -> prove DDS phase/sample generation.

TEST 3:
full loopback
  -> DDS -> capture -> FIFO -> controller -> SPI master -> SPI slave.

Only move to the next test after the previous test passes.

## Vivado project setup

Create a new RTL project.

Add all files under rtl/ as Design Sources.

Add asynch_fifo_tb.v as the first Simulation Source and set
tb_asynch_fifo as the simulation top.

Create/configure dds_compiler_0 in Vivado. Do not add its generated
demo_tb/tb_dds_compiler_0.vhd to the project's simulation sources.

After DDS configuration matches dds_top.v, add the loopback TB.

Do not create multiple module definitions with the same module name.

There must be exactly one:
- module asynch_fifo
- module dds_top
- module spi_master
- module spi_slave
- module spi_controller
- module uart_fifo_dds_core

The board-level top wrapper is top_wrapper.v. Keep it out of the first FIFO-only simulation; use it only for implementation after RTL simulation is proven.
